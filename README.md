# ServerDenemeleri

Server projesi için C# ile geliştirilmiş bir uygulama.

## 📋 Proje Hakkında

Bu proje, C# kullanarak geliştirilmiş bir server uygulamasıdır. Çeşitli server işlevlerini test etmek ve geliştirmek amacıyla oluşturulmuştur.

## 🚀 Başlarken

### Gereksinimler

- .NET SDK (önerilen sürüm 6.0 veya üzeri)
- Visual Studio veya Visual Studio Code
- C# derleyici

### Kurulum

1. Projeyi klonlayın:
```bash
git clone https://github.com/TroubledKezoo1/ServerDenemeleri.git
```

2. Proje dizinine gidin:
```bash
cd ServerDenemeleri
```

3. Gerekli bağımlılıkları yükleyin:
```bash
dotnet restore
```

4. Projeyi derleyin:
```bash
dotnet build
```

## 💻 Kullanım

Projeyi çalıştırmak için:

```bash
dotnet run
```
